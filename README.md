# Pizza-Sales-Performance-Dashboard

📌 Project Overview

This project analyzes pizza sales data to generate meaningful business insights using SQL, Excel, and Power BI. The objective was to evaluate sales performance, identify trends, and create interactive dashboards for decision-making.

🛠 Tools & Technologies

SQL – Data cleaning, transformation, and KPI calculation

Microsoft Excel – Dashboard creation and data visualization

Power BI – Data modeling and interactive dashboard design

📊 Key Performance Indicators (KPIs)

Total Revenue

Total Orders

Total Pizzas Sold

Average Order Value

Average Pizzas per Order

📈 Analysis Performed

Sales by Pizza Category

Sales by Pizza Size

Daily & Monthly Order Trends

Top 5 & Bottom 5 Best-Selling Pizzas

Revenue Contribution Analysis

🔄 Project Workflow

Imported raw dataset into SQL database

Performed data analysis using SQL queries

Extracted KPIs and aggregated metrics

Imported data into Excel for dashboard creation

Connected SQL database to Power BI

Built an interactive Power BI dashboard

🎯 Project Outcome

The dashboard provides clear insights into sales performance, customer preferences, and revenue trends, enabling data-driven business decisions.
